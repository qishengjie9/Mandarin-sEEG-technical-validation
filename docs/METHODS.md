# Analysis methods

## Time-frequency validation

The single-channel workflow removes the linear trend, applies a fourth-order
zero-phase Butterworth band-pass filter, and suppresses specified line-noise
frequencies with zero-phase notch filters. Power spectral density is estimated
with Welch's method. Time-frequency power is obtained by FFT convolution with
complex Morlet wavelets whose length increases from three cycles at the lowest
frequency to ten cycles at the highest frequency. Power at each frequency is
expressed in decibels relative to the user-specified baseline interval.

Canonical delta, theta, alpha, beta, gamma, and high-gamma time courses are
formed by averaging linear power within each band and then normalizing to the
baseline mean. The principal high-gamma summary is

```text
10 * log10(mean speech-period power / mean baseline-period power).
```

The command performs descriptive technical validation of a selected channel;
it is not a population-level statistical test. Channel selection and effect
confirmation should use independent data to avoid circular analysis.

## Acoustic-contamination screen

Audio and sEEG signals are converted to raw power spectral density
spectrograms using 200 ms Hamming windows sampled at 50 Hz. Before spectrogram
calculation, the audio waveform is centered by subtracting a 1 s moving
average. This suppresses slow baseline displacement while preserving the
speech-frequency fluctuations relevant to the contamination test.

For every sEEG channel, signed Pearson correlations are calculated between
each audio-frequency bin and each sEEG-frequency bin over 75-1000 Hz. The lower
bound focuses the test on frequency-specific acoustic or microphonic coupling
and reduces dominance by low-frequency neural activity and movement-related
components. The contamination matrix contains, for each audio-by-sEEG
frequency pair, the maximum signed correlation across channels.

The mean equal-frequency diagonal of this matrix is compared with surrogate
diagonal means generated by randomly shuffling either rows or columns. This
preserves broad horizontal or vertical correlation structure while testing
whether equal-frequency alignment is enriched. The default implementation uses
10,000 permutations and a fixed random seed for reproducibility.

These metrics are screening indicators rather than automatic exclusion rules.
Peak same-frequency coupling, full-matrix diagonal enrichment, signal quality,
channel anatomy, and sensitivity analyses should be considered together.

## Within-participant lexical-tone decoding

Each trial is represented by low-frequency activity (0.5-40 Hz) and
high-gamma amplitude (70-150 Hz). The public preprocessing pipeline applies
common-average re-referencing, 50/100/150 Hz notch filtering, event-normalized
temporal resampling, and baseline standardization. Stimulus-grouped outer folds
keep repeated instances of the same lexical item within one split. The default
STAG-Mandarin model combines shared temporal filters, adaptive electrode-graph
attention, channel pooling, temporal context encoding, and a four-class tone
head. Balanced accuracy is the primary metric.

## Cross-participant lexical-tone decoding

The cross-participant analysis holds out the participants specified in the
configuration before model development. Variable electrode sets are processed
with shared temporal filters, permutation-equivariant set attention, dynamic
channel pooling, and channel dropout. Tone decoding is supported by initial and
final auxiliary heads, a supervised contrastive objective, and gradient-reversal
subject-domain regularization. Results represent zero-calibration transfer to
held-out participants on a partially shared phonological inventory; they should
not be described as a definitive unseen-word benchmark.
