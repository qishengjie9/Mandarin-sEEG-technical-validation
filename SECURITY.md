# Security and privacy

Do not submit participant data through GitHub issues, pull requests, release
assets, email attachments, or public cloud links. This includes raw sEEG,
speech audio, trial-level annotations, electrode coordinates, clinical details,
access tokens, and screenshots containing restricted information.

Training artifacts require the same review. Do not publish trial manifests,
preprocessing caches, checkpoints, prediction archives, or logs until local
paths and participant-level disclosure risks have been assessed. Aggregate
metrics and figures may be released only after approval under the dataset's
governance process.

Potential code vulnerabilities may be reported privately to the repository
maintainers at the institutional contact address listed in the final release.
Replace this paragraph with the approved security contact before publication.
